# content/ — where the library came from

`dashboard/adhd_library.json` is a mined, attributed extract: short quotes, one-line tips, step lists and protocols. It is not a copy of any book. Every item carries `source` and `module`.

| Module ids | Source | Where the full material lives |
|---|---|---|
| `unscattered-*` | *The Unscattered Mind* — Heel Wisenthiel | `~/Downloads/adhdbookskills/source/unscattered-*` |
| `pai-*` | *The Personal AI Assistant Manual* — Daniel Payne | `source/pai-*` |
| `augmented-*` | *AI Productivity for ADHD Professionals* — Alex R. Sterling | `source/augmented-*` |
| `aligned-*` | *ADHD ALIGNED* — G. Rysen | `source/aligned-*` |
| `anchor-method` | The ANCHOR Method & Workbook (research synthesis, 2026) | PMO project attachment |
| `emergency-card`, `affirmations`, `reset-pack` | ADHD Emergency Card, ADHD Affirmations, ADHD Reset Pack (PDFs) | `~/Downloads` |

Regenerate: re-run the content miner over those folders; keep the schema in `dashboard/control-room.html` (`lib.modules/quotes/tips/exercises/protocols/affirmations/emergency_card`).

Known weakness, carried from the skill pack's own test report: four modules answer "I cannot start" and overlap. The dashboard merges them into one "Cannot start" card and draws from whichever are switched on.
