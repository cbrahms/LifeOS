## Strategies
<!-- updated: 2026-10-21 by:claude source:operating-record §4, ANCHOR -->
- S1 — One primary build at a time; the sequence is public on the dashboard, where Nicole can see it.
- S2 — One metric: shipped units per week. Logged, charted, reviewed Sunday.
- S3 — Externally delivered single actions, never a system that must be opened voluntarily: the capsule is the first screen; morning push to come.
- S4 — Energy-scaled asks: two 90-minute blocks on a high day, one 25-minute floor task on a low day; a floor day is a success.
- S5 — Interest-bridging: attach a neglected value to an engine value (design the wind-down; beat last week's number).
- S6 — Never miss twice; re-enter at the next-smallest-step; no redesign on a lapse.
- S7 — New tool or framework → parking lot. The question is always "what is the shipped unit this week?"
